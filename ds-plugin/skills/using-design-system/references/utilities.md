# Classes utilitárias

Para layout de página. Estilo de componente vem das props do componente.
Classe fora desta lista é CSS custom e vai para review.

| Classe | Faz | Token |
|---|---|---|
| `ds-stack-{md,lg}` | Coluna flex com gap vertical | `space.stack.*` |
| `ds-inset-{sm,md}` | Padding interno | `space.inset.*` |
| `ds-text-{default,subtle}` | Cor de texto | `color.text.*` |
| `ds-visually-hidden` | Esconde visualmente, mantém para leitor de tela | — |
| `ds-truncate` | Uma linha com reticências | — |

Não existem utilitários de cor de fundo nem de margem arbitrária, de propósito.
